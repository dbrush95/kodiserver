# Kodi Server
A home media management portal for Raspberry Pi OS Lite (64-bit).

The portal runs inside Cockpit, using your Pi account for login and its authenticated terminal. It manages Kodi recovery backups and connects to an existing Plex server. It does not turn subscription Kodi add-ons into a streaming server.

Implementation and installation instructions are being prepared on the `codex/pi-portal` branch.
